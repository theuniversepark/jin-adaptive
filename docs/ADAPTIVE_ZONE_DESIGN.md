## 2. 존 정의와 다른 존과의 관계

- 목적: 가공 중 데이터와 가공 후 품질측정 데이터로 공정 상태를 자율 판단(정지·변경·구동)하고, 가공기와 VLA(Vision-Language-Action) 로봇이 협동하는 '상태 적응형 가공'을 실증함 [R3]
- 역할: 밀링·선삭·초정밀 측정·리워크 폐루프 [R7]
- R&D 대응: 총괄1-세부2 WP7 "물리 시뮬레이션 Sim-to-Real 고정밀 공정지향(적응가공)" — 캠틱 주관, 애드아임(밀링 AI·엣지)·생기원(선삭 AI·엣지)·텔로스(Cell DT)·KETI(VLA AMR)·레인보우로보틱스(AMR HW)·대승정밀(실공정) [R4]
- 연계: 3차년도 연계공정 "적응가공 → 측정 → 리워크", AI정밀검사(QMS) 존 A-4-5가 적응가공 제품(하우징·블록·커버류)을 재측정·리워크 판단 [R1]
- 정밀조립 존과의 차이: 정밀조립은 1차년도 실장비 셀(A-3-5)이 있으나 적응가공은 1차년도에 시뮬레이션 셀(A-2-5, 23.2억)만 구축함 → 이 시뮬레이터가 A-2-5의 운영 시나리오·DT 검증 도구 역할을 함 [W1][W3]

## 4. 적응가공 폐루프 (A-2-5 통합 OCS)

| 단계 | 시뮬레이션 동작 | 레거시 | 자동화 | 피지컬AI | 근거 |
|---|---|---|---|---|---|
| 소재 스캔 | 프리폼 가공여유 편차(±0.3mm) 측정 → 공구경로 보정 | ID 확인만 | 스캔 | 스캔 | [R5 16장] |
| 적응 공구경로 | 가공여유가 작을수록 에어컷 단축 | 0% | −12% | −18% | KPI 가공시간 단축율 2차 12% → 5차 20% [R4] |
| 진단 | 채터·마모를 소리·진동·스핀들 부하·AE로 진단 | 없음 | <40ms | <14ms | KPI 진단 1차 <40 → 5차 <14ms [R4] · "가공기 내부 카메라 불가 → 외부 신호" [W2 9/28] |
| 보정 | Feed −12% · Speed −8%씩 최대 3회 | 없음 | <50ms | <20ms | 제어응답 1차 <50 → 5차 <20ms · 최대 3회 자율복구 [R4] |
| 복구 실패 | 셀 HOLD → 상위 보고 → 공구교체 (오케스트레이터 인시던트) | — | 정비원 | 정비 휴머노이드 | 셀 즉각 조치 / 상위 판단 2레벨 [W1] |
| 공구 관리 | 공구마다 실제 마모 속도가 다름 | CNC 카운터 30개 고정 교체 (빨리 닳는 공구 파손) | 실측 수명 <20% 교체 | 실측 수명 <22% 교체 | 공구 예지보전 [R4] · 현장 애로 "공구 조기마모·파손" [R6 p.12] |
| 측정·판정 | CMM 공차 ±20µm(설계 추정) — 합격 / 잔량 리워크 / 과삭·파손 폐기 | 샘플 35% (30분 4EA 자주검사) | 전수 | 전수 | 치수 전수는 셀 내, 샘플링은 측정 셀 [W2 10/1] |
| 환류 | 측정 편차 × 이득을 상류 셀 공구 오프셋에 반영 | 24개마다 수기 반영 | 매 측정 ×0.45 | 매 측정 ×0.65 | 측정 → 공구경로·가공조건·보정값 변경 [W3] |

- 오차 모델(설계 추정): 치수 편차 = 열변위(웜업 평형 9~15µm, 30분 시정수) + 공구 마모(수명 1%당 0.12µm) − 공구 오프셋 + 소재 편차 잔여분 + 채터 + 잡음
- 공구교체는 기존 정비 체계에 `tool` 종류로 넣었음 — 정비실에서 "교체 공구 세트(프리셋 공구·툴홀더·더미가공 시편)"를 챙겨 출동, 툴 프리셋 후 오프셋 재설정, ERP(Odoo) 정비요청 기록
- 현장 이벤트 재해석: 바닥 누유 → **절삭유 바닥 오염**, 바닥 이물질 → **바닥 칩 비산** — 현 문제점 "절삭유 바닥 오염(AMR 청소)" [R6 p.12]
