# Jin-3D 적응가공 — 피지컬AI 실증 메타팩토리 적응가공 존(A-2) 운영 시뮬레이터

정밀조립 존 시뮬레이터 [jin-3d](https://github.com/theuniversepark/jin-3d)와 같은 플랫폼 위에 **적응가공 존**을 올린 3D 운영 시뮬레이션임.
같은 Zone을 **레거시 → 자동화 → 피지컬AI 자율** 3단계로 바꿔 가며 운영하고, 적응가공의 핵심인 **가공–측정–판정–보정–재가공 폐루프**를 눈으로 확인할 수 있음.

- 설계 근거·셀 구성·폐루프 규칙·미확정 사항: [docs/ADAPTIVE_ZONE_DESIGN.md](docs/ADAPTIVE_ZONE_DESIGN.md)
- 공통 플랫폼 기능(오케스트레이터 · CCTV · 5G · ERP · AAS · VLA · AIOS 등) 설명: [docs/PLATFORM.md](docs/PLATFORM.md)

## 실행

```bash
cd /Users/jin/Projects/adaptive-machining
npm install            # 처음 한 번
npm start              # http://localhost:8765  (PORT=8766 npm start 로 포트 변경)
npm run app            # 맥 앱 창으로 실행 (Electron)
npm test               # 시뮬레이션 테스트 26종 (적응가공 폐루프: tests/adaptive.mjs)
```

- API 키 없이도 추론 기반 에이전트로 운영됨. Claude 연동은 `.env`의 `ANTHROPIC_API_KEY` 또는 앱 ⚙ 설정
- 화면 확인용 스크린샷: `npx electron tools/shot.cjs <폴더> dark 600 zone,mill,cmm`

## 적응가공 존 구성

```
소재 투입 ─► ①소재 식별·3D측정셀 (공동)
              ├─► 유압블록 : ②5축 가공셀(A-2-1) ─► ③사선·디버링셀(A-2-1)  ─┐
              └─► 리어커버 : ④정밀절삭셀(A-2-2) ─► ⑤선삭·AI품질셀(A-2-3) ─┴─► ⑥초정밀 측정·리워크셀(A-2-4, CMM)
                                                                                 ├─ 합격 → 제품별 적재
                                                                                 ├─ 잔량 NG → 리워크 → 재측정
                                                                                 └─ 과삭·파손 → 폐기
        ▲ CMM 측정 편차 → 상류 가공셀 공구 오프셋 환류
```

| 셀 | 설비 | 로봇 (피지컬AI) |
|---|---|---|
| 1. 소재 식별·3D측정 | 소재 ID · 구조광 3D 스캐너 게이트, 가공여유 히트맵 | AMMR×2 |
| 2. 유압블록 5축 가공 | 5축 수평 MC (트러니언 · ATC · 칩 컨베이어 · 절삭유 · 엣지 디바이스) | 6축 로봇 머신텐딩 |
| 3. 유압블록 사선·디버링 | 기울어진 스핀들 드릴 헤드 · 세척 터널 | 협동로봇×2 |
| 4. 리어커버 정밀절삭 | 5축 MC | 6축 로봇 머신텐딩 |
| 5. 리어커버 선삭·AI품질 | 복합 터닝센터 (척 · 터렛 · 절삭력 동력계) | 6축 로봇 머신텐딩 |
| 6. 초정밀 측정·리워크 | 판정 게이트 · 문형 CMM(AMR 진입) · 리워크 스핀들 | AMMR×2 |

- 제품(대승정밀): **브레이크 유압제어블록** A6082-T6 125×136×44mm(지그 팔레트당 4개) · **8속 리어커버** ADC12 270×255mm. Blender 모델(`assets/blender/hblock.glb`, `rcover.glb`)이 소재 → 가공 → 사선홀·보어 상태로 바뀜
- 혼류 비율: 왼쪽 Zone 카드에서 1:1 · 2:1 · 1:2 · 유압블록만 · 리어커버만
- 머신텐딩: 6축 로봇이 AMR 위 팔레트를 집어 가공기 문 → 지그에 안착하고, 가공(문 닫힘 · 스핀들/척 회전 · 절삭유 · 칩) 후 꺼내 AMR에 내려놓음. 채터 보정 중에는 엣지 LED·조작반이 주황
- 정밀조립 대비 바뀐 점: 조립·체결·포장셀 → 가공·디버링·선삭·CMM셀, 포장 대신 판정 라벨, 현장 이벤트는 절삭유 바닥 오염 · 바닥 칩 비산

## 적응가공 폐루프 (A-2-5 통합 OCS) — 왼쪽 Zone 카드 아래 패널

| | 레거시 | 자동화 | 피지컬AI |
|---|---|---|---|
| 가공 조건 | 고정 NC 프로그램 | 소재 3D 스캔 공구경로 보정 (가공시간 −12%) | PA Agent 자율 적응가공 (−18%) |
| 채터 | 감지 수단 없음 (가공면 떨림) | 엣지 AI 진단 <40ms · 보정 <50ms | 진단 <14ms · 보정 <20ms · 3회 자율복구 |
| 공구 | CNC 카운터 30개 고정 교체 (빨리 닳는 공구 파손) | 실측 수명 <20% 예지 교체 | 실측 수명 <22% · 정비 휴머노이드 공구 자동교체 |
| 측정 | 샘플 검사 (30분 4EA 자주검사) | CMM 전수 → 리워크 분기 · 매 측정 오프셋 환류 | 같음 (환류 이득 상향) |

패널에는 진단·보정 평균 지연(목표 대비), 채터 자율복구율, CMM 1회 합격률·리워크·폐기, 공구교체·파손, 셀별 공구 수명 막대·계통 편차·Feed/Speed override, 최근 24건 치수 편차 산점도, 폐루프 이벤트가 나옴.
3단계 8시간 비교(같은 조건): 양품 1,460 → 2,422 → 3,387개, 유출 불량 111 → 0 → 0, 공구 파손 13 → 6 → 0 — 수치는 예시용 가정값으로 돌린 결과임.

## 미확정 · 가정값

사이클타임, 공차(±20µm), 공구 수명, 셀 치수·좌표는 문서에 확정값이 없어 시뮬레이션용 가정값을 썼음. 실측·레이아웃 용역 결과가 나오면 `js/line.js`(`ZONE_RECIPES`, `ZONE_CELLS` 좌표)와 `js/adaptive.js`(`ADAPT_MODES`, `TOL_UM`)만 바꾸면 됨. 자세한 목록은 설계 문서 6장.
